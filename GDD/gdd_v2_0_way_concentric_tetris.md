## 2. 界面布局与分区规划（16:9）

整体画面采用**左重右稳**的黄金分割式排版，保证玩家在高频决策时余光即可扫完所有关键信息：

- **左侧主体区（约占宽度 50%–55%，近全高）**：**完整正方形游戏棋盘**（无切角），边缘带微弱流光外框，内部承载 12×12 网格、中心生成核心、八向星芒准星与落点虚影。
- **右上方状态区**：半透明玻璃质感 HUD 面板，默认英文标签，集中展示 `SCORE`、`LEVEL`、`RINGS`、`NEXT`、`HOLD` 以及单一蓄能能量条（`CHARGE`），并在右上角提供 `EN / 中文` 语言切换、静音与暂停入口。
- **右下方看板娘区**：独立角色立绘框 + 浮动气泡对话框，承载腹黑毒舌人设的 **Gemini AI 娘（Gemini AI-chan）**，根据实时战局切换表情并弹出双语吐槽。

## 3. 核心玩法机制

### 3.1 棋盘结构（12×12 完整正方形）

- **网格规格**：`12 × 12` 偶数对称网格，保证中心生成区与四面外墙完全对齐。
- **中心生成区**：正中央 `4 × 4` 区域为方块生成与安全警戒区。
- **同心环分层**：中心区以外共有 **4 层同心方框环**，从最外层到最内层周长依次为：
  - 第 1 环（最外圈）：**44 格**（约 11 个标准四格块）
  - 第 2 环：**36 格**
  - 第 3 环：**28 格**
  - 第 4 环（紧贴中心区）：**20 格**

### 3.2 方块两阶段生命周期

每个新方块都严格经历“中心悬停瞄准 → 发射飞行与锁定”两个阶段：

1. **阶段一：中心悬停与八向瞄准**
   - 方块在正中 `4 × 4` 核心区生成，外围出现环形倒计时进度条与八向罗盘箭头（`↑ ↓ ← → ↖ ↗ ↙ ↘`）。
   - 悬停期间玩家可自由旋转方块并切换瞄准方向；边缘同步显示该方向下的最终落点虚影。
   - **主动发射**：确认方向后按下发射键，方块立刻沿当前方向射出。
   - **超时发射**：倒计时归零时，若玩家已选定方向则按该方向发射；若全程未操作任何方向，则系统从 8 个方向中**随机抽取一个方向盲射**。

2. **阶段二：飞行微调与三级贴墙滑行**
   - **正四向微调**：向正上/下/左/右飞行时，垂直于飞行方向的两键负责平移微调，同向键负责加速推进（Soft Drop）。
   - **斜四向微调**：遵循物理直觉，无需背表——以向左上 `↖` 飞行为例，按 `↑` 或 `→` 向靠上墙的轨道偏移 1 格，按 `←` 或 `↓` 向靠左墙的轨道偏移 1 格。
   - **三级渐进式贴墙滑行**（以 `↖` 为例）：
     1. 优先检测左上方下一格，畅通则直接斜向推进。
     2. 若斜向受阻，分别检测正左与正上；哪一侧畅通即顺着墙面或已有方块边缘自动滑行，直至卡入角落或障碍物。
     3. 若左上、正左、正上三向全堵，进入约 **0.25 秒的锁定宽限期（Lock Delay）**，允许最后一次微调旋转，随后正式锁定。
   - **实时落点虚影（Ghost Piece）**：瞄准与飞行全程，沿“斜飞 + 贴墙滑行”的真实路径在目标边缘绘制半透明落点轮廓。

### 3.3 同心环消除、8 向外扩与失败条件

- **任意环独立消除**：4 层同心环中，**任意一层率先填满**即立刻触发消除（不强制必须先消最外圈），防止外圈留洞导致死局，并支持高手刻意铺垫实现**双环/三环共振连消**。
- **局部 8 向外扩规则**：
  - 消除第 $k$ 环后，**仅第** $k$ **环以内**的剩余方块按 8 方向向外扩张 1 格（第 $k$ 环以外的方块保持不动）。
  - **顶角自动补位**：内圈位于对角线上的 4 个拐角格沿 45° 斜向弹出，直接补入外圈的四个顶角；直边方块正交外推 1 格。由于外圈比内圈多 8 格，新空出的位置自然留在**敞开的直边上**，从中心直接发射即可填补，彻底避免角落封死（Soft-lock）。
- **失败条件（Game Over）**：任意方块锁定后侵入中心 `4 × 4` 生成区，导致下一个方块无法正常生成，即判定游戏结束。

## 4. 操作方案（三套输入无缝并行）

浏览器环境下默认**小数字键盘、WASD/方向键、鼠标**三套输入同时生效，玩家动哪套系统即响应哪套，零切换成本：

| 操作动作 | 小数字键盘（单手八向推荐） | WASD / 方向键（经典街机） | 鼠标 + 辅键（零门槛） |
| :--- | :--- | :--- | :--- |
| **中心八向选向** | `7 8 9` / `4 6` / `1 2 3` 单键直出 | 单按正四向；双键同按选斜向（如 `W+A`） | 鼠标绕中心划动，准星自动吸附最近方向 |
| **旋转方块** | `0` / `Enter`（或 `+` / `-` 双旋） | `Q / E` 或 `Z / X` | 鼠标右键 / 滚轮 |
| **提前发射 / 瞬降** | 正中 `5` 键 | `Space` | 鼠标左键 |
| **飞行中微调** | `7 8 9` / `4 6` / `1 2 3` | `WASD` / 方向键 | 左手 `WASD` 微调，或依赖悬停精准瞄准 |
| **暂存方块（Hold）** | `.` 或 `C` | `C` | 鼠标中键 / 侧键 |
| **释放蓄能块** | `/` 或 `Shift` | `Shift` | 键盘 `Shift` 或点击 HUD 能量槽 |
| **暂停 / 恢复** | `Esc` / `P` | `Esc` / `P` | 点击右上角暂停图标 |

> 交互防误触说明：键盘选斜向时，悬停阶段按下方向键仅调整准星指向，不会立刻发射；需按下发射键或等待倒计时结束才会射出，避免双键组合时因先后手差几毫秒导致误射。

## 5. 方块池、难度模式与递增曲线

### 5.1 开局难度模式选择

游戏开局提供两种难度模式，并直接绑定不同的星核急救块机制：

| 难度模式 | 星核急救块（满能激活） | 核心体验定位 |
| :--- | :--- | :--- |
| **Easy（简单模式）** | **Nova Bomb（微型星爆弹）**：1×1 核心，撞击首个障碍后炸毁周围 `3 × 3` 区域 | 解压友好，濒死时可一键清场救命，适合新手上手 |
| **Hard（困难模式）** | **Stardust Piercer（星尘穿透弹）**：1×1 核心，无视外层阻挡直接精准落入被埋死的单格空洞 | 纯粹策略向，考验精算补洞与多环共振规划 |

### 5.2 改良 Bag 洗牌方块池

采用“每袋洗牌抽完再换袋”的机制，防止极端随机导致连续刷出难放方块：

- **主力方块（75%–80%）**：经典 7 种四格俄罗斯方块（`I, O, T, J, L, S, Z`）。
- **补角润滑小块（20%–25%，随等级递减）**：
  - **3 格小拐角（Tromino L）**：专治四个顶角，斜向发射严丝合缝。
  - **2 格短条**：修补 8 向外扩后留在直边上的 2 格窄缝。
- **稀有急救块**：**1 格单点核心**不进入常规高频池，仅作为低频保底（约每 20 块出 1 个）或连消奖励出现。

### 5.3 三杠杆难度递增曲线（每消 2–3 环升 1 级）

| 等级区间 | 中心悬停倒计时 | 飞行速度 | 润滑小块占比 | 玩家体验定位 |
| :--- | :--- | :--- | :--- | :--- |
| **Lv 1–2** | 2.0 秒 | 慢速（充裕微调） | 25% | 熟悉八向瞄准、贴墙滑行与落点虚影 |
| **Lv 3–5** | 1.5 秒 | 中速 | 20% | 结合 `NEXT` 提前在脑中规划发射方向 |
| **Lv 6–8** | 1.1 秒 | 偏快 | 15% | 高压微决策，稍一犹豫即触发超时盲射 |
| **Lv 9+** | 0.8 秒（下限） | 高速 | 10% | 极限街机心流，保留人类视觉与按键极限窗口 |

## 6. 进阶机制、计分公式与充能数值

### 6.1 轻度进阶机制

- **瞬发抢跑（`QUICK!`）**：方块生成后 **0.5 秒内**（倒计时剩余 75% 以上）完成选向并主动发射，触发金色流光尾迹、清脆提示音、额外加分与充能加速；连续抢跑可叠节奏连击，超时盲射则直接断连。
- **暂存槽（`HOLD`）**：每回合限用一次，方便把 3 格小拐角等关键补角块留到最佳时机使用。
- **单一蓄能槽（`CHARGE`）**：通过消环与 `QUICK!` 抢跑蓄能，满格（100%）后手动激活，将下一块替换为对应难度的 1×1 急救星核（Easy 为星爆弹，Hard 为穿透弹）。

### 6.2 计分与充能数值表（初版试玩基准）

| 得分 / 充能事件 | 基础分值 | 能量槽充能 | 备注 |
| :--- | :--- | :--- | :--- |
| **单环消除（Single Ring）** | `1,000 × Level` | `+25%` | 若为最外圈（44 格），额外 `+20%` 分数 |
| **双环共振（Double Ring）** | `2,800 × Level` | `+65%` | 刻意攒双环回报远高于连消两次单环 |
| **三环超共振（Triple Ring）** | `6,000 × Level` | **直接 100% 满格** | 触发全屏彩虹冲击波 |
| **四环全爆（Quad Burst）** | `12,000 × Level` | **直接 100% 满格** | 极难达成的传奇操作 |
| **全盘清空（All Clear）** | `+10,000 × Level` | `+50%` | 消环后棋盘归零的额外大奖 |
| **瞬发抢跑（`QUICK!`）** | `+100 × Level` | `+8%` | 连续抢跑每多 1 连击再 `+25`（上限 `+250`） |
| **瞬降落位（Hard Drop）** | 每跳过 1 格 `+10` | — | 鼓励高手干脆利落 |

- **连消倍率（Ring Flow）**：在 **12 个方块落位以内**再次完成消环，总得分依次乘以 `×1.2 → ×1.5 → ×2.0 → ×2.5（封顶）`。

## 7. 界面流转与状态规划

整体由 **Title Screen → Gameplay ⇄ Pause Overlay → Game Over** 四个核心状态构成，并支持从结算页 0 等待快速重开：

- **Title Screen（标题页）**：
  - 暗夜星光动态背景配缓慢旋转的棱镜同心环；右上角常驻 `EN / 中文` 切换与音量静音按钮。
  - 主体展示 `ANTIGRAVITY TETRIS` 发光 Logo 与两张并排难度卡：**`EASY`（Nova Bomb 3×3）** 与 **`HARD`（Stardust Piercer 1×1）**，支持点击或键盘 `←/→ + Enter` 极速开局。
  - 底部提供轻量弹窗入口：`CONTROLS`（三套键位图解）与 `HIGH SCORES`（分难度榜单）。
- **Gameplay Intro（对局入场）**：
  - 开局播放约 **0.9 秒的 3-2-1 中心聚焦热身动画**，避免玩家手尚未就位就触发第一块超时盲射。
- **Pause Overlay（暂停遮罩，`Esc` / `P`）**：
  - **防偷看保护**：暂停时自动对左侧 12×12 棋盘施加高斯模糊与暗化遮罩，防止通过反复暂停精算落点。
  - 居中磨砂弹窗提供：`RESUME`（恢复前带 0.6 秒短倒计时）、`RESTART`（快捷键 `R`）、`CONTROLS`、`LANGUAGE (EN / 中文)`、BGM/SFX 音量滑块、`AI Commentary (ON / OFF)` 开关及 `BACK TO TITLE`。
- **Game Over & Local High Scores（结算页与本地高分榜）**：
  - 失败瞬间先播放约 **0.8 秒的中心过载红光 + 棋盘失重定格演出**，随后平滑浮现结算卡。
  - 战绩摘要：`FINAL SCORE`（破纪录亮起 `NEW RECORD!` 徽章）、`RINGS CLEARED`、`MAX FLOW COMBO`、`QUICK! RATE`（抢跑率）。
  - **分难度本地榜单**：基于本地存储（`localStorage`）分别记录 **Easy Top 5** 与 **Hard Top 5**（含分数、等级与日期）；底部按 `Enter` / `Space` 可立刻 `PLAY AGAIN`，也支持一键 `SWITCH DIFFICULTY`。

## 8. 视听爽感与特效反馈规范（Juice Spec）

整体听觉基调定位为**空灵 Synthwave / Lo-Fi 电子乐**，所有互动音效统一锁定在同一大调五声音阶内，保证高速连击与消环时的旋律和谐感：

| 游戏事件 | 视觉与粒子反馈 | 镜头与定帧（Hitstop） | 音效与音乐反馈 |
| :--- | :--- | :--- | :--- |
| **中心选向切换** | 对应方向箭头高亮，虚线与落点虚影瞬间吸附 | 无 | 极轻脆的机械星盘拨动音（`tick`） |
| **倒计时最后 0.4s** | 中心倒计时环由青蓝转为品红/琥珀并急促脉冲 | 无 | 节奏加快的轻心跳提示音 |
| **`QUICK!` 瞬发抢跑** | 飞行尾迹变为金色光带，中心弹出 `QUICK!` 小浮字 | 轻微反冲缩放 | 清亮高频光束音；连续抢跑时音阶逐级上扬 |
| **方块落位锁定** | 落地瞬间微弹性回弹（`1.08 → 1.0`），接触边迸出 4–6 颗细小晶体火花 | 极轻触底感 | 通透的水晶/玻璃轻敲声 |
| **单环消除** | 整环先白光定帧，随后顺时针扫过棱镜光波并炸散为晶体碎片粒子 | **50ms 定帧** + 轻震（`2px, 120ms`） | 悦耳合成器和弦；连消倍率越高、和弦越明亮 |
| **8 向外扩位移** | 消环后延迟 `120ms`，内圈方块带轻微弹性缓动（`180ms`）同步滑向外圈 | 无 | 干脆的磁吸“咔哒”归位音，强化几何可读性 |
| **多环共振（2+ 环）** | 全屏径向彩虹冲击波 + 高密度星尘爆发，棋盘外框短暂流光暴走 | **90–120ms 定帧** + 强震（`6px, 240ms`） | 史诗级上行合成器琶音 + 看板娘同步惊呼 |
| **星核急救块释放** | Easy：红金爆波清空 3×3；Hard：细长星尘光束穿墙点亮目标洞 | `80ms 定帧` + 中震（`4px, 180ms`） | 蓄能释放音 + 爆破低频（Easy）或激光穿透音（Hard） |
| **濒危警戒（剩 1 层）** | 中心 4×4 警戒框红光慢呼吸闪烁 | 无 | BGM 自动叠加轻鼓点/高频滤波，拉满紧迫感 |

## 9. 右下角看板娘：Gemini AI-chan（腹黑毒舌系统）

### 9.1 角色设定与反差感

- **定位**：自称“星核轨道高阶观测 AI”，表面挂着甜美礼貌的微笑，实际极度腹黑毒舌。最喜欢把玩家的失误一本正经地记录为“珍贵的人类算力衰退样本”；当玩家打出惊艳操作时，会短暂瞳孔地震，随后立刻嘴硬找补（“一定是手滑蒙中的吧？”）。
- **交互克制与防刷屏规范**：
  - **全局冷却**：普通吐槽间隔 **6–8 秒**；高优先级事件（双环共振、星核释放、濒危警戒、All Clear、Game Over）可立即打断当前气泡。
  - **停留与去重**：每条气泡停留约 **3.2 秒**后轻柔淡出；同一事件台词池洗牌轮播，不连续重复同一句。
  - **可选开关**：暂停菜单提供 `AI Commentary: ON / OFF`，照顾专注冲榜的玩家。

### 9.2 6 套核心表情差分（轻量高表现力）

| 表情状态 ID | 画面特征 | 主要触发场景 |
| :--- | :--- | :--- |
| `Smug`（招牌腹黑笑） | 眼尾微弯、自信浅笑、带星光高光 | 默认待机、日常阴阳怪气 |
